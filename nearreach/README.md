# NearReach

AI-powered **hyperlocal marketing-to-commerce** platform for multi-location brands — inspired by suites like [SingleInterface](https://www.singleinterface.com/).

## What's included

| Module | Capability |
| --- | --- |
| **Presence** | Local listings, publisher sync, store page content |
| **Reputation** | Multi-platform review inbox & reply workflows |
| **Engagement** | Q&A, messages, chat, social threads |
| **Spotlight** | Hyperlocal ad campaigns with CPL & conversions |
| **Call Leads** | Intent, sentiment, transcripts, conversion status |
| **Transactions** | Location catalogs, inventory, local orders |
| **Hyper Xai** | Audience segments, interaction intelligence |
| **Configuration** | Location toggles, roles, reputation workflows |

Plus a marketing landing page and a unified dashboard overview.

## Run locally

```bash
cd nearreach
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Dashboard: [http://localhost:3000/dashboard](http://localhost:3000/dashboard).

## Stack

- Next.js (App Router) · React · TypeScript · Tailwind CSS · Lucide icons
- Demo data in `src/lib/mock-data.ts` (no backend required)

## Note

This is a product demo / reference implementation with mock data. Real publisher APIs, ad networks, telephony, and commerce integrations are out of scope for this scaffold.

# NearReach — Hyperlocal Marketing Platform

This repository contains **NearReach**, a demo multi-location marketing-to-commerce platform inspired by [SingleInterface](https://www.singleinterface.com/).

## Quick start

```bash
cd nearreach
npm install
npm run dev
```

- Marketing site: http://localhost:3000  
- Product dashboard: http://localhost:3000/dashboard  

See [`nearreach/README.md`](nearreach/README.md) for the full module list.

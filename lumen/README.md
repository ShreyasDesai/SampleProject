# Lumen

All-in-one **SEO · ASO · GEO · AIO** visibility workspace.

Lumen helps teams illuminate brand discovery across:

- **SEO** — Search Engine Optimization
- **ASO** — App Store Optimization
- **GEO** — Generative Engine Optimization
- **AIO** — AI / Answer Optimization

## Quick start

```bash
cd lumen
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Workspace

| Module | Path | What it audits |
|--------|------|----------------|
| Overview | `/app` | Module picker |
| SEO | `/app/seo` | Title, meta, keywords, content depth |
| ASO | `/app/aso` | App name, subtitle, keyword field, description |
| GEO | `/app/geo` | Brand entities, definitions, citeability |
| AIO | `/app/aio` | Question/answer packages, facts, sources |

Each analyzer returns a score, grade, metrics, prioritized insights, and detected terms. Sample content is preloaded — click **Analyze** to see results, or edit the fields and re-run.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

# Lumen

Competitive intelligence platform for **SEO · ASO · GEO · AIO** — built to rival Ahrefs / Semrush workflows, with generative & answer-engine visibility included.

## Modules

| Module | Path |
|--------|------|
| Dashboard | `/app` |
| Site Explorer | `/app/site-explorer` |
| Keywords Explorer | `/app/keywords` |
| Competitive Gap | `/app/competitors` |
| Site Audit | `/app/site-audit` |
| Rank Tracker | `/app/rank-tracker` |
| Backlink Profile | `/app/backlinks` |
| Content Lab | `/app/content` |
| ASO Intelligence | `/app/aso` |
| GEO Visibility | `/app/geo` |
| AIO Answers | `/app/aio` |

## Run

```bash
cd lumen
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Data note

The UI is production-grade. Metrics are generated by a **deterministic synthetic index** (same domain/keyword always yields the same portfolio) so the product can be demoed end-to-end without paid crawl APIs. Swap the `src/lib/intel` adapters for DataForSEO, your own crawlers, or store APIs for live data.

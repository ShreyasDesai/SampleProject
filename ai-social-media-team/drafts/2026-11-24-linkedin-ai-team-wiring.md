## Post

My social media team has a kill switch: one file that stops every AI agent on it.

I set up my own social media team as AI agents in Claude Code: one orchestrator and eight departments. Here is how it is wired, and where I stay in control.

The orchestrator reads the signals, scores the week and writes one brief per job. It never drafts, publishes or spends.

The eight departments do the work: drafting, design, scheduling, replies and reports. They never brief each other.

Right now, every post waits in an approval queue until I tick a box. No agent ticks a box.

A draft that breaks my tone rules is held for me. It is never quietly fixed.

Every action gets one line in a log, so I can see what happened.

And the kill switch: if that STOP file exists, every agent stops before its next action. Only I can remove it.

If you build an agent team, write down what each agent may never do before you write what it does.
